# VulnChain

Automated vulnerability scanner that chains multiple vulnerabilities to identify complex attack paths in enterprise environments.

## Features

- Multi-host scanning with dependency resolution
- Automatic vulnerability chaining
- Real-time reporting dashboard
- Integration with Nmap, Nuclei, and custom modules

## Tech Stack

- Python 3.11+
- Nmap integration
- Nuclei templates
- REST API
